## ⚠️ CI is green on less than you think

Nine test files need the 86 MB Scryfall card database, are written with
`describe.skipIf`, and therefore **skip on a machine without it, leaving the run
green.** CI holds types, build, source integrity, the conformance corpus, the
unit suite and the 500-seed fuzz gate. It does **not** hold §6 gate 1's database
half or gate 5 (the coverage accounting) — those run locally:

```
node scripts/cardgen/verify.cjs --full
```

That command, green, is what must be true before a batch lands. `AGENTS.md`'s
own §8 amendment records this rather than pretending otherwise.

## The loop

**The loop is PROVEN — M6.4a ran it end to end** (D158): eight scripts landed,
`verify.cjs --full` green, all five gates. Batches can scale now, but
⚠️ **classify every selected card against what the engine CONSULTS before
drafting it** — `select.cjs` emits every sole-need-`scriptable` card, and a
card whose only text is an activated ability is unlandable until the
`ActivatedDef` seam is built (D158's headline reportable; it cost 4 of the
first batch's 12).

```bash
node scripts/cardgen/select.cjs 25
```

Then, per card in `scripts/cardgen/batch.json`:

1. Read the card's **real oracle text** from the local database —
   `node electron/cardsvc-worker.cjs --query "<name>"`. Never a paraphrase, never
   from memory. This is D15b's rule and it has caught real drift.
2. Write `src/engine/scripts/cards/<moduleName>.ts`, exporting one
   `<MODULE_NAME>_SCRIPT`.
3. Write its test beside it, asserting on **EVENTS** rather than final state where
   possible.
4. Add the card to `fuzz.node.test.ts`'s `SCRIPTS` **and** its `DECK`.

```bash
node scripts/cardgen/land.cjs <moduleName>
node scripts/cardgen/verify.cjs --full
```

**Every landed card owes, in the same commit:** its `tier3.ts` note silent,
`engineComplete` accepting it, a place in the fuzz pool, and its tests. All four
are enforced by tests rather than by convention — `shippedScripts.node.test.ts`
and `fuzz.node.test.ts` between them.

## Non-negotiable constraints

- ⚠️⚠️ **Never use `git stash` or `git restore`.** The tree carries ~90 files of
  uncommitted work sitting on an old HEAD. Undo by editing, or by string surgery
  against a verified marker.
- ⚠️ **The generator may never touch `src/engine/`** outside `scripts/cards/` and
  the one `SHIPPED_SCRIPTS` line that imports from it. Primitives are hand-written
  reviewed work — that is where correctness for *every* card is decided, and a
  generated change to a primitive is a change to every card at once.
- **Scripts return EVENTS.** They are never handed a mutation API. `ctx.random` is
  a seeded scratch RNG threaded through the log, so a coin-flip card replays
  bit-exactly.
- **A script that cannot be verified is not landed.** No exceptions, no "mostly
  works" tier.
- **Never half-execute** (D90). A card the parser understands only in part must
  not run its understood half silently — that is the one outcome worse than not
  running it at all.
- **An unenforced category must be SAID** (D122/D124). Silence in this app means
  "handled"; 16,020 cards once said nothing at all.
- `src/engine/` is pure and deterministic: no React/Electron/Node/zustand, no
  `Date.now`/`Math.random`/`performance.now`. `src/bot/` additionally may not
  import a `GameState`-taking engine module or read `process.env`.
- **Offline-first is absolute.** Approved exceptions are listed in `AGENTS.md`.
  ⚠️ §7 names popularity data as an internet dependency — **stop and ask the user
  before fetching any.**

  line probe carried an Equip line's PRINTED index; an Equipment whose Equip
  follows another activated line (its own animation) has its Equip at 1, and the
  generated suite activated index 2 and was refused "no such ability". The probe
  reads the engine's own activated list for the index now.
- **THE LINE PROBE RUNS BEFORE THE PORT, NEVER AFTER** (D395). Re-run after the
  wave had landed, it read every rowed card as complete, dumped no lines, rowed
  nothing, and emptied the names and modules lists the close-out reads; they
  were rebuilt from the module files. A probe that reads completeness describes
  the tree it runs on.
- **TWO OPERANDS ARE TWO INDICES ON ONE CLAUSE** (D396, CR 701.12). A bite or a
  fight names its subject (a target, the self, or the referent) and its OTHER
  target (`otherTargetIndex`, a second index `parseEffects` hands out after the
  subject's, in printed order); the executor resolves the object through the
  same `picksFor` / `aimOf` the subject went through, and emits ONE `DamageDealt`
  with one or two entries through `damageTo`, so deathtouch, lifelink, infect and
  wither ride along. Either operand gone or not a creature at resolution is no
  damage at all (CR 701.12b/c), said aloud.
- **A DERIVED GENERATOR RENAMES ITS OWN COMMENTS** (D396, D362). An anchor that
  quotes the previous decision's comment ("D395 - an animated permanent ...")
  matches nothing in the derived copy, which already says D396. Quote the
  renamed text, or anchor on code.
- **THE PREDICATE NAMES THE RETIREMENTS; THE OLDER SUITES WITHOUT IT ARE A LATENT
  DUPLICATE** (D396, D187, D295). Thirteen hand fight and bite scripts went red on
  the suppression predicate and retired; twenty-two others (Pounce, Savage Smash
  ...) stayed green only because their suites predate the predicate test. A script
  the vocabulary reads whole still runs by the script - harmless, and a reportable.
- **A COST IS READ OFF THE CARD, NOT REMEMBERED** (D396). Two in-play proofs paid
  one mana for a {1}{R} and a {1}{G} spell and were refused `cannotAfford`; the
  harness says so plainly, and the fix is one number, but the number comes from
  the fixture's text.
- **THE GENERATOR PROBES ITS OWN ASSERTS WITH A NULL ROW** (D396). `needsKw` and
  `needsBoard` render the assert lines once with no row to decide which helpers
  the suite declares; an assert arm that reads the row's own base without a
  guard crashes the whole generation with "reading 'base'" three frames away
  from the arm. Guard the row in every self-aimed assert.
- **A CONDITION ON A STATIC IS PROVEN WITH IT BROKEN** (D388, D381). A suite
  reads the subject at its printed base with the condition unmet - broken FIRST
  where the armed board already satisfies it (untapped, no untapped lands, a
  hand size) - then meets it and reads the static. A condition the card itself
  satisfies (an artifact creature under "you control an artifact") has no unmet
  stage and its title says so.
- **A COUNTER THE STAGE PUTS MOVES P/T ON ITS OWN** (D388). "As long as it has a
  +1/+1 counter on it, it gets +1/+0": the counter is layer 7d, so the met read
  is base + the counter + the static, and a -1/-1 counter on a 7/2 reads 6/1
  with the static absent. When the fixture IS the count, it moves what it
  counts (D387's corollary).
- **A CREATURE THAT CANNOT BE BLOCKED NEVER SEES A DECLARE-BLOCKERS PROMPT, AND
  THE STATIC UNDER PROOF MAY BE WHAT MAKES IT ONE** (D388, D232/D234). "As long
  as it's attacking, it has flying": waiting for the prompt runs the combat out
  and reads the static gone. Read the moment the attack is declared, with
  combat live and no prompt asked for.
- **A STATIC'S CONDITION HELPER IS DERIVE-FREE** (D388, D317). It is asked
  INSIDE a derive, so the engine's activationConditionsHold (which derives)
  cannot be reused; read ctx.state, the PRINTED faces, the turn record, the
  life totals and the live combat.
- **THE STAGE LIVES ON THE ROW: A STAGE FIX IS A RE-ROW** (D388). The row maker
  stores each condition's stage lines beside the descriptor, so regenerating
  from the old rows after fixing the reader reproduces the old suites byte for
  byte. Re-row, then regenerate.
- **COUNT THE BACKSLASHES AGAINST THE ORIGINAL LINE** (D388, invariant 14). A
  node patch that hoists a regex arrives with its doubled backslashes halved, and
  a template literal cooks the lone escape to a bare letter - silently. A swap
  anchor spelled with a doubled backslash-n arrives as a real newline and matches
  nothing. Spell a backslash by String.fromCharCode(92) and compare counts.
- **A COUNTED FIXTURE MUST MOVE THE COUNT AND NOTHING ELSE** (D387). An attached
  count proven with Accorder's Shield or Holy Strength would read their own
  `+0/+3` and `+1/+2` on top of the pump's delta; Swiftfoot Boots (hexproof and
  haste) and Pacifism (can't attack or block) are P/T-neutral. And an Equipment
  that counts "Equipment attached to it" COUNTS ITSELF once equipped - the
  starting count is 1, not 0, and the generator computes it.
- **A BLOCKED ATTACKER MAY DIE IN THE SAME COMBAT - PROVE THE COUNT ACROSS
  GAMES, NOT TURNS** (D387). A becomes-blocked pump is read right after the
  trigger resolves in the declare-blockers step, in one game blocked by one
  creature and another blocked by two; a second attack next turn presumes the
  attacker survived the first. `advanceUntil(... awaiting?.kind ===
  'declareBlockers')` stops ON the prompt because the prompt is the predicate
  (D370's trap is a predicate that holds without it), and the defender declares
  the blocks by hand.
- **A NEGATIVE PUMP GETS ONE STEP** (D387, D323). `-1/-1` per counted thing on a
  2/2 host: one step reads 1/1, a second reads 0/0 and the SBA bins the host
  before the assert. One counted in, one counted out, on a host that survives.
- **A PRICER'S REGEX IS A MEASUREMENT AND IT CAN HIDE HALF THE FAMILY** (D387).
  The variable-pump pricer required a `+` before the power, so every negative
  pump was invisible to the count that chose the widenings - twelve cards.
  Price with the sign the GENERATOR reads, and re-price after widening the
  reader: 0 -> 33 landable was the measurement, not 21.
- **A TEST AT THE EDGE OF ITS BUDGET FAILS UNDER THE SHARDED GATE'S OWN LOAD**
  (D387, D269). The fuzz rewind test runs in EVERY shard at once; at 18.7 s
  idle it read 25.8-30.6 s in four of six shards against the 20 s default,
  every assertion green. Measure it ALONE first (a timeout with green asserts
  is a budget, not a hang), then give it an explicit budget - the sibling
  projection-leak test carries 60 s - and rerun the gate from the top.
- **A DERIVE'S OWN REPLACE TABLE IS NOT SAFE FROM THE SED THAT MAKES IT**
  (D387, D378 again). `sed 's/386/387/'` over a derive whose table contains
  `['d386', 'd387']` produces `['d387', 'd386']`. Write the next derive by hand
  with an explicit take-list.
- **ONE PASSING LEG IS A SAMPLE, NOT A FLOOR** (D386, correcting D385; D155/D176).
  D385 made the static-prevention canary's floor unconditional because one
  60-seed leg passed it. D386's 21 new scripted names shifted every seed's
  round-robin window (D193) and the same 60 seeds read ZERO, while 500 read 77
  with every shard positive. A floor is set where the fuel is RELIABLE - measured
  more than once at the size it asserts - and softening it back to gate size on
  that evidence is a correction, not the weakening D385's own fallback note
  warned against (which is softening with NO new measurement to pass a red gate).
- **A CONDITION IS PROVEN BY THE FIRE THAT DOES NOT HAPPEN** (D381). Firing once
  with a condition MET proves the ability resolves and says nothing about the
  condition. Fire twice - broken, then met - with the stage-one check as a THROW
  inside the arm, where the mark is in hand; and refuse a payload the arm cannot
  read rather than widening the read.
- **A FIXTURE DERIVATION MUST ANSWER EVERY FIELD THE FILTER CARRIES** (D381). One
  that ignores a field hands the suite a card that does not satisfy it - a
  while-you-control-a-TOKEN condition was given a Badlands. D350 rule: a filter
  no fixture satisfies REFUSES the row, and is never given one that ignores it.
- **A NAME THAT IS A RULES WORD** (D373). `selfRef` spells a card own name
  `~` before any rule runs, so the card named Regenerate arrives as "~ target
  creature." and reads as nothing. Ledger it under THAT, not under the
  mechanic it appears to be waiting for.
- **THE UNTAP SYMBOL IS A COST AND ITS OFFER IS GATED ON BEING TAPPED**
  (D373). `legal.ts` skips a `requiresUntap` ability while the permanent is
  UNTAPPED, so a `{Q}` row is not offered at all until the scaffold taps the
  recipient - which is also the only way an untap PAYLOAD is observable
  (D128). The generator taps first in both cases.

## Open reportables you inherit

0. ⚠️⚠️ **`select.cjs` EMITS SPELLS THE PIPELINE CANNOT LAND** (D160). A spell
   executes through the effect vocabulary or not at all — `CardScript` has no

   (D159). `Sacrifice this <type>` is a chargeable price now, offered only
   when the game's registry carries the `ActivatedDef` — so each of those
   cards is ONE DEF away from executing, on machinery two landed cards
   already prove. A general sacrifice cost ("Sacrifice a creature") is a
   CHOOSER the activation stage does not have, and stays unpaid.

   No script that needs randomness may ship until it is wired.

   `session.targetSpecsFor(card)` with no face index, so a modal-DFC back face

Commander-legal cards now execute completely, up from Y"* — never as a count of
